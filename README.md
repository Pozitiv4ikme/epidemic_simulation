## Simulation description
This simulation models the spread and mutation of a virus in a city.  
The city is represented as a two-dimensional grid, where each cell can contain a specific location (e.g., hospital, home) and a certain number of people.  
Individuals can move around the city, become infected, recover, or die — regardless of whether they were previously sick or healthy.
